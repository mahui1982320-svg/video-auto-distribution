> 面向团队运营的多平台视频发布控制台：统一管理素材、平台账号、发布任务、发布记录和员工权限。

## 项目定位

这是“视频全自动分发”系统，而不是通用的脚本合集。系统以 Web 控制台为入口，将经过授权的平台账号、视频素材和发布任务统一到一个可审计的工作流中。

它适合需要由多位同事协同运营多个内容平台的团队。每个账号均需由账号所有者完成平台要求的登录或扫码验证；系统不会绕过平台的安全机制或使用未授权账号。

## 功能

- 素材库：上传、预览、删除和追踪视频素材的发布状态。
- 发布中心：一个任务选择多个平台账号，填写标题、简介、标签和发布时间。
- 账号管理：按平台管理授权账号及其登录状态。
- 团队协作：管理员、运营等角色与操作审计记录。
- 发布记录：按任务和目标平台查看提交结果、日志和失败原因。
- 内容辅助：对上传视频生成标题和简介建议，仍由运营人员最终确认。

## 支持的平台

发布能力依赖各平台的公开网页流程及其持续变化。当前项目包含抖音、视频号、快手、小红书、Bilibili、百家号、TikTok、YouTube 等适配器；请在上线前逐个平台完成登录和真实发布验证。

## 本地启动

### 1. 准备环境

```bash
git clone git@github.com:mahui1982320-svg/video-publisher.git
cd video-publisher
python3.10 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
pip install -e '.[web]'
```

### 2. 构建前端并启动控制台

```bash
cd sau_frontend
npm install
npm run build
cd ..
python team_web.py
```

默认监听 `127.0.0.1:5409`。首次启动会创建本地数据目录。生产环境请使用反向代理与 TLS，不要把开发服务器直接暴露到公网。

### 3. 首次使用

1. 使用管理员账号登录控制台。
2. 在“员工管理”中创建运营人员并分配角色。
3. 在创建发布任务时添加或选择平台账号，并由账号所有者完成扫码登录。
4. 上传素材，选择平台账号，填写审核后的标题与简介后提交任务。
5. 在“发布记录”中核对每个平台的提交结果。

## 合规与使用边界

- 仅管理拥有合法发布权的账号和素材。
- 遵守各平台服务条款、内容审核规则与频率限制。
- “提交成功”表示适配器已完成当前网页提交流程；请以平台侧最终内容状态为准。
- 不在仓库、Issue 或日志中上传账号 Cookie、密码、二维码或个人敏感信息。
